# Références de format Claude Code

Consultées le 11 septembre 2026 :

- [Créer des sous-agents personnalisés](https://code.claude.com/docs/en/sub-agents) : emplacement `.claude/agents/`, frontmatter, outils, modèles et mémoire persistante.
- [Mémoire de projet Claude Code](https://code.claude.com/docs/en/memory) : `CLAUDE.md`, règles de projet et mémoire automatique.
- [Créer des skills Claude Code](https://code.claude.com/docs/en/slash-commands) : emplacement `.claude/skills/<nom>/SKILL.md` et invocation par commande.
- [Configuration Claude Code](https://code.claude.com/docs/en/configuration) : portée de `.claude/settings.json`.
- [Outils Claude Code](https://code.claude.com/docs/en/tools-reference) : noms utilisés dans les listes d’outils des agents.

Les exigences métier, cliniques, juridiques et d’hébergement ne sont pas certifiées par ce kit. Les agents demandent des sources primaires actuelles et une validation compétente avant toute conclusion qui engage le produit.
