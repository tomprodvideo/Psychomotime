Sources externes vérifiées le 2026-09-11 pour tout travail touchant aux instruments psychométriques du produit. À revérifier avant d'agir : les conditions éditeurs changent.

**Sécurité des instruments**
- ITC, *The ITC Guidelines on the Security of Tests, Examinations, and Other Assessments*, v1.0, 6 juillet 2014, réf. `ITC-G-TS-20140706` : https://www.intestcom.org/files/guideline_test_security.pdf
  Le PDF n'est pas lisible par WebFetch (binaire) — le télécharger puis l'ouvrir avec l'outil Read en mode `pages`.
  Points utiles : p.8 (l'éditeur possède le contenu et en autorise l'usage), p.9 (le champ couvre explicitement le clinique), p.12 (transcription = menace recensée), p.14 §7/§11/§12 (stockage, transferts, NDA, territorialité).

**Licences éditeur — les deux batteries outillées dans le produit sont diffusées par ECPA / Pearson France**
- Conditions d'utilisation des matériels psychométriques + CGV : https://www.pearsonclinical.fr/pub/media/wysiwyg/France/commande_condition_ecpa.pdf
  **Réserve** : la version récupérée mentionne des échéances 2018 — version en vigueur à demander à l'éditeur.
  Interdits explicites : reproduction de tout ou partie, adaptation sur un autre support que celui prévu, mise à disposition à des tiers non compétents. Obligation d'employer le test « dans sa version originale et dans sa globalité ».
- Niveaux de qualification (psychomotriciens = niveau A) : https://www.pearsonclinical.fr/niveau-qualification
- Branche UK du même groupe, clause la plus directement applicable au produit — interdiction de saisir le contenu dans un logiciel de cotation tiers : https://www.pearsonclinical.co.uk/legal/terms-of-sale-use.html

**Droit français (Légifrance)**
- CPI L.122-4 (reproduction partielle et adaptation illicites) : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006278911
- CPI L.122-5 (exceptions limitatives) : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006278917
- CPI L.341-1 (droit sui generis du producteur de base de données — fondement pour les tables d'étalonnage) : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006279245
- CSP R.4332-1 (le bilan psychomoteur est un acte du psychomotricien) : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006914164
