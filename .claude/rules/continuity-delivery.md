# Continuité et livraison

- Les décisions durables vivent dans `docs/context/DECISIONS.md` ou dans un ADR, avec date, statut et conséquence.
- `docs/context/CURRENT_STATE.md` décrit seulement l’état démontré par le code et les vérifications.
- Les questions non résolues vivent dans `docs/context/OPEN_QUESTIONS.md`; ne pas les convertir silencieusement en choix.
- Avant une livraison, vérifier le diff, les migrations, les autorisations, les secrets, la compatibilité, le retour arrière et les environnements ciblés.
- GitHub versionne les agents, skills et documents. Vercel n’est pas un stockage de mémoire pour Claude Code.
- Ne jamais pousser, fusionner ou déployer sans autorisation explicite. Ne jamais effectuer de push forcé.
